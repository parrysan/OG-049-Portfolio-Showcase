Stage types, one per step

Each stage type, in action.

  1. Each letter or part rises in with its meaning beside it, set in the brand's own typeface.Best for The brief, when the name itself carries the idea.
    mmonoclonal
    Abantibody
    Vvaccine

    Example: mAbV.

    decode
  2. The artwork sits large while leader lines draw in from each feature to its label.Best for The core design idea, when it lives inside the artwork.

    Feature one, drawn from the artwork

    Feature two, on the outline

    Feature three, inside the mark

    Example: the mAbV shield.

    anatomy
  3. The explored options sit side by side, then slide together into the one that was chosen.Best for Logo routes, layout options or concepts (four to six).

    Example: STR's logo routes.

    converge
  4. The old colour floods into the new one, with the spec set large: Pantone, HEX, RGB.Best for A colour change with a clear before and after.
    Before: tealPantone2728 CCobalt Blue
    HEX
    #0047BB
    RGB
    0 · 71 · 187
    flood
  5. Swatches grow up from the baseline, each with its name and value.Best for A full palette, or several colours with roles.

    Primary#0A5F8A

    Dark#084A6D

    Light#3D8AB5

    Tint#E6F2F7

    Secondary#0D9488

    Trust#059669

    Example: STR's six colours.

    palette
  6. The artwork on the left, the photo of it in the world on the right.Best for A deliverable next to its real application.

    Artwork on the left, the real thing on the right.

    pair
  7. A real screenshot in a browser frame. The optional size ladder renders the actual logo files at real sizes.Best for Websites and design-system pages; add a size ladder for marks.

    Example: mAbV design system.

    window
  8. The desktop page in a browser frame, with the phone version sliding up beside it.Best for Any site where mobile matters.

    Example: STR product page.

    responsive
  9. Do and Don't side by side; the Don'ts are struck through.Best for Writing style, logo usage, accessibility do's and don'ts.

    Do

    “Synthetic QS-21-Api demonstrates equivalent activity.”

    “Secure supply chain.”

    Don't

    “Our amazing product boosts vaccines like never before.”

    “The best adjuvant on the market.”

    Example: STR writing rules.

    rules
  10. A screen with a row of facts underneath: files, formats and counts stagger in.Best for Brand kits, file sets, component libraries.
    • Digital4 SVG · 4 PNG
    • Print4 PDF · 4 EPS
    • Social1 SVG · 1 PNG
    manifest
  11. Two to four portraits fan out on the brand's deep colour.Best for Real-world photos or phone screens: the proof step.

    Example: phones and an office photo.

    fan
  12. Any single image, contained or covering the stage, on any background.Best for Diagrams, infographics, a single strong picture.

    Example: STR catalogue manager.

    image
